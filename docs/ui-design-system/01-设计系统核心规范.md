# NocoBase UI设计系统 - 核心规范
## 设计理念：专业商务风 + 微科技感
---
## 1. 颜色系统
### 主色调定义
| 颜色类型 | 色值 | 应用场景 |
|----------|------|----------|
| 主品牌色 | `#165DFF` | 按钮、链接、选中状态、高亮元素 |
| 功能强调色 | `#FF7D00` | 关键操作点、警告状态、提示信息 |
| 成功色 | `#00B42A` | 成功状态、完成标识 |
| 警告色 | `#FF7D00` | 警告提示、风险提示 |
| 错误色 | `#F53F3F` | 错误状态、失败提示 |
| 信息色 | `#86909C` | 辅助信息、提示文字 |
### 中性色阶
| 层级 | 色值 | 应用场景 |
|------|------|----------|
| 纯白 | `#FFFFFF` | 页面主背景 |
| 浅灰1 | `#F2F3F5` | 卡片背景、次要背景 |
| 浅灰2 | `#E5E6EB` | 边框、分割线 |
| 浅灰3 | `#C9CDD4` | 禁用状态边框 |
| 深灰1 | `#1D2129` | 主标题、核心内容 |
| 深灰2 | `#4E5969` | 次要内容、正文 |
| 深灰3 | `#86909C` | 辅助文字、提示信息 |
| 深灰4 | `#C9CDD4` | 禁用文字、占位符 |
### 科技感增强配色
| 效果类型 | 值 | 应用场景 |
|----------|------|----------|
| 渐变主色 | `linear-gradient(135deg, #165DFF 0%, #4080FF 100%)` | 关键按钮、头图、品牌展示 |
| 光晕效果 | `0 0 20px rgba(22, 93, 255, 0.15)` | hover状态、选中状态 |
| 毛玻璃效果 | `backdrop-filter: blur(8px); background: rgba(255, 255, 255, 0.8)` | 弹窗、浮动面板 |

## 2. 字体系统
### 字体选型
- 主字体：`Inter` - 现代无衬线字体，专业商务场景首选
- 等宽字体：`JetBrains Mono` - 代码展示、配置项展示
- Fallback：`-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, sans-serif`
### 字体层级规范
| 层级 | 字号 | 字重 | 行高 | 应用场景 |
|------|------|------|------|----------|
| H1 | 32px | 600 | 40px | 页面大标题、功能入口标题 |
| H2 | 24px | 600 | 32px | 模块标题、卡片标题 |
| H3 | 20px | 600 | 28px | 次级模块子标题、功能组标题 |
| H4 | 16px | 600 | 24px | 卡片标题、列表项标题 |
| Body1 | 14px | 400 | 22px | 正文内容、表单标签 |
| Body2 | 12px | 400 | 20px | 辅助文字、提示信息、说明 |
| Caption | 12px | 400 | 18px | 标签、状态提示、小字说明 |
---
## 3. 间距与布局系统
### 间距规范（8px栅格系统）
| 尺寸 | 大小 | 应用场景 |
|------|------|----------|
| XS | 4px | 细微间距（图标与文字间距、内边距微调） |
| S | 8px | 小间距（列表项间距、小卡片内边距） |
| M | 16px | 标准间距（卡片内边距、模块间距） |
| L | 24px | 大间距（页面边距、模块组间距） |
| XL | 32px | 超大间距（页面顶部/底部边距、大模块间距） |
| XXL | 48px | 特大间距（页面区块间距） |
### 圆角规范
| 类型 | 大小 | 应用场景 |
|------|------|----------|
| 标准圆角 | 8px | 卡片、面板 |
| 控件圆角 | 6px | 按钮、输入框 |
| 小圆角 | 4px | 标签、提示框、小元素 |
| 大圆角 | 12px | 模态框、大卡片、重点模块 |
### 阴影系统
| 类型 | 值 | 应用场景 |
|------|------|----------|
| 卡片阴影 | `0 2px 8px rgba(0, 0, 0, 0.06)` | 普通卡片 |
| 悬浮阴影 | `0 4px 16px rgba(0, 0, 0, 0.08)` | 悬浮状态、弹窗 |
| 强调阴影 | `0 8px 24px rgba(0, 0, 0, 0.12)` | 重点模块、弹窗 |
| 科技感阴影 | `0 0 0 2px rgba(22, 93, 255, 0.1), 0 4px 12px rgba(0, 0, 0, 0.08)` | 选中状态、激活状态 |

## 4. 图标系统
### 规范要求
- 基础图标库：Ant Design 官方图标库，统一线稿风格
- 自定义图标：线性风格，24x24网格系统，2px线条粗细
- 状态规范：默认`#86909C`，hover`#165DFF`，禁用`#C9CDD4`
- 科技感增强：关键功能图标增加微妙渐变填充
