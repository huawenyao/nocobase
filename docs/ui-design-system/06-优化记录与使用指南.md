# NocoBase UI 优化记录与使用指南

## 优化总览

本次UI优化基于"专业商务风 + 微科技感"的设计理念，对整个系统进行了全方位的升级，包括设计系统落地、全局框架优化、核心组件改造和体验精细化提升四个阶段。

---

## 🎯 优化成果

### 1. 设计系统落地 ✅

#### 颜色系统
- **主色调**：`#165DFF`（专业蓝），兼顾商务稳重和科技感
- **辅助色**：`#FF7D00`（橙色，用于强调和警告）
- **成功色**：`#00B42A`，错误色：`#F53F3F`
- **中性色**：从纯白到深灰的渐变色阶，确保信息层次清晰
- **双主题支持**：亮色/暗色主题一键切换，自动保存用户偏好

#### 字体系统
- **主字体**：`Inter`，现代无衬线字体，跨平台一致性好
- **等宽字体**：`JetBrains Mono`，用于代码和配置展示
- **字体层级**：H1-H4 + 正文/辅助文字的清晰层级

#### 间距系统（8px栅格）
- XS: 4px，S: 8px，M: 16px，L: 24px，XL: 32px，XXL: 48px
- 页面边距：24px，区块间距：24px，组件间距：16px

#### 圆角系统
- 按钮/输入框：6px，卡片/面板：8px，模态框/弹窗：12px
- 小圆角（4px）：用于标签、提示框等小元素

---

### 2. 全局框架优化 ✅

#### 导航系统
- **头部高度**：64px，布局更开阔
- **侧边栏宽度**：240px，菜单展示更舒适
- **主题切换**：集成在头部右侧，支持亮色/暗色/跟随系统三种模式
- **菜单交互**：hover/active效果优化，选中状态左侧蓝色高亮条

#### 布局系统
- 响应式设计，适配桌面、平板、移动端
- 统一的页面边距和区块间距
- 支持自定义工作台布局

#### 全局反馈
- 统一的Message/Notification/Modal样式
- 反馈位置避开头部导航，视觉更协调
- 微动画过渡，体验更流畅

#### 通用组件
- **空状态组件**：支持无数据、无权限、404、网络错误等多种场景
- **骨架屏**：优化加载动画，视觉更舒适

---

### 3. 核心组件优化 ✅

#### 表格组件
- 行高统一为48px，平衡信息密度和舒适度
- 取消斑马纹，用hover和选中高亮替代
- 分页优化，显示总数、页码跳转、每页条数选择
- 空状态统一，支持自定义操作按钮
- 行hover/选中微交互效果，提升体验

#### 表单组件
- 默认水平布局，标签宽度140px
- 表单项间距统一为24px
- 标签和输入框之间间距16px
- 输入框hover/focus效果优化
- 实时校验，错误提示紧跟输入框

#### 按钮组件
- 微交互效果：hover上移1px，active回弹
- 阴影效果优化，主按钮自带品牌色阴影
- 点击缩放反馈，操作感更强

---

### 4. 体验精细化优化 ✅

#### 微交互动画
- 所有可交互元素统一过渡效果（0.2s cubic-bezier(0.4, 0, 0.2, 1)）
- 页面切换淡入淡出效果
- 模态框缩放进入动画
- 骨架屏脉冲加载动画
- 滚动条hover效果

#### 无障碍优化
- 统一的焦点状态样式，键盘导航友好
- 禁用状态样式清晰，支持高对比度模式
- 减少动画模式支持，适配特殊用户需求
- 移动端点击区域≥44px，符合无障碍标准

#### 性能优化
- 启用硬件加速，提升动画流畅度
- 优化重绘区域，提升渲染性能
- 滚动性能优化，支持顺滑滚动
- 打印样式优化，适配打印场景

#### 其他优化
- 滚动条样式统一，亮色/暗色主题适配
- Toast/Message样式优化，毛玻璃效果
- 下拉菜单hover时轻微右移，增强反馈
- 卡片hover上移效果，层次感更强

## 📖 使用指南

### 主题切换
1. 点击页面头部右侧的主题切换按钮
2. 选择"亮色模式"、"暗色模式"或"跟随系统"
3. 选择会自动保存到本地，下次打开时自动应用

### 自定义配置
#### 表格配置
- 支持自定义显示列
- 支持调整列宽
- 支持保存视图模板
- 支持批量操作和行内编辑

#### 表单配置
- 支持水平/垂直布局切换
- 支持自定义标签宽度
- 支持表单分组和折叠

#### 工作台配置
- 支持拖拽调整卡片位置和大小
- 支持添加/移除卡片组件
- 支持多模板切换
